What it does

One small command-line tool replaces dozens of manual clicks in YouTube Studio for every release across several channels.

⬆️

Full-quality uploads

Original masters go straight to YouTube, with no browser size limits and no re-compression before upload.

🗓️

Scheduling

Releases go out privately, unlisted, public, or at a set time in the channel's time zone.

🖼️

Thumbnails & playlists

Custom thumbnails and playlist placement are applied as part of the same release.

🌍

Localization

Translated titles and descriptions plus caption tracks in several languages reach viewers worldwide.

Built for one owner

Studio Uploader is not a public service. Only its owner uses it, to manage the owner's own channels.

Revoke access at any time

Access can be removed in one click at myaccount.google.com/permissions.

  • Minimal access. It only uploads and edits videos and reads the channel name to confirm the right channel.
  • Stays local. Sign-in tokens are kept only on the owner's computer.
  • No sharing. No data is sold, shared, or used for advertising.
  • Google policy. It complies with the Google API Services User Data Policy, including Limited Use.
  • YouTube terms. It uses YouTube API Services under the YouTube Terms of Service.
