Privacy Policy

Last updated: 30 October 2026

Who we are

Studio Uploader is a private tool. Its owner uses it only to manage the owner's own YouTube channels.

Data accessed

With the owner's permission through Google OAuth, the tool uses the YouTube Data API to:

  • upload videos;
  • set titles, descriptions, tags, thumbnails, playlists, translations and captions;
  • read the channel name and ID to confirm which channel is connected.

Storage

OAuth tokens are stored only on the owner's computer. They are never uploaded to any server.

Sharing

No data is sent to third parties, sold, or used for advertising. No data from other users is collected.

Revoking access

You can revoke access at any time at myaccount.google.com/permissions.

Google and YouTube policies

Studio Uploader's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It uses YouTube API Services: see the YouTube Terms of Service and the Google Privacy Policy.
