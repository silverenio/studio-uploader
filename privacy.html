Privacy Policy

Last updated: 30 October 2026

Studio Uploader is a private tool used only by its owner to manage the owner's own YouTube channels.

Data accessed

With the owner's permission (Google OAuth), the tool uses the YouTube Data API to upload videos and to set titles, descriptions, tags, thumbnails, playlists, translations and captions on the owner's channels, and to read the channel name and ID to confirm which channel is connected.

Storage and sharing

OAuth tokens are stored only on the owner's own computer. No data is sent to any third party, sold, or used for advertising. No data from other users is collected.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Studio Uploader's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.
